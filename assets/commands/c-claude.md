Crie (ou **mescle**, preservando o que já existe) o `CLAUDE.md` na raiz do repo a partir de
`.claude/skills/schematize-c/assets/CLAUDE.md`. Não apague regra existente; se já houver uma
seção de C, **atualize-a** e diga o que mudou. Se o repo é de app, o `CLAUDE.md` da
**`schematize-mobile`** vem junto — e, no que é de app, é ele que manda.
